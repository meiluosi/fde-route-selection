# 示例：信贷材料字段抽取（教学假设，不是客户事实）

演示 Skill 的顺序：先过滤硬约束，再选路线，后比模型；以及“硬约束未清最多 Investigate”。

**本目录所有数字、答复和单价都是教学假设**，价格不代表任何真实报价，也不是默认值。真实项目要用客户数据、带日期的价格记录和客户样本实测替换。

| 文件 | 内容 |
|---|---|
| [constraint-gate.md](constraint-gate.md) | 假设的客户答复如何淘汰公有云 API 选项，哪些仍待确认 |
| [cost-sheet.md](cost-sheet.md) | 按调用计费与私有化两种成本结构的对比，含盈亏平衡和量级敏感性 |
| [route-card.md](route-card.md) | 选型决策卡：路线、候选池、结论 Investigate 及重开条件 |

场景设定：某银行信贷部门要从客户提交的材料（营业执照、财报、流水摘要）中抽取固定字段，供审批人核对。上游问题定义卡与 ramp 数字为假设输入，未单独提供。
