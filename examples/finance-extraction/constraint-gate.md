# 硬约束清单（教学假设）

场景：信贷材料字段抽取　　所针对的环节：审批前的字段录入与核对

| ID | 约束内容 | 客户原话（假设） | 当前答案 | 状态 | 淘汰了什么 | 回答方 |
|---|---|---|---|---|---|---|
| C1 | 含客户身份信息的材料能否发往外部服务 | “身份信息不能出我们的网络” | 不能 | 客户确认（假设：信息安全部，已记录人与日期） | 公有云 API 处理原始材料 | 信息安全 |
| C2 | 脱敏后的材料能否用于外部服务 | “脱敏标准我们没定过” | 未明 | 待确认 | 暂不淘汰：公有云 API 处理脱敏后文本 | 信息安全、法务 |
| C3 | 专有云（客户云租户）是否可用 | “云团队在评估” | 未明 | 待确认 | 暂不淘汰 | IT |
| C4 | 机房私有化硬件与运维 | “有 GPU 预算，运维人力不确定” | 部分 | 冲突（预算与运维说法不一致） | 暂不淘汰 | IT、采购 |
| C5 | 国产化/采购名录要求 | “还没问采购” | 未明 | 待确认 | 暂不淘汰 | 采购 |
| C6 | 是否有可用于评测的真实样本 | “可以在内网里用” | 可内网使用 | 客户确认 | 评测只能在客户环境内进行 | 业务 |

部署三问：
- 推理在哪里跑：C1 之后只剩客户环境内（专有云或机房）；C2 若通过，脱敏文本方案重新进入候选。
- 数据去哪里：原始材料不出网络（客户确认）；脱敏后是否可出，待确认。
- 谁来运维：待确认（C4 冲突）。

门槛结论：
- 已清：C1、C6。
- 未清：C2–C5。公有云 API 对脱敏文本的路径、专有云、机房私有化三者暂不可淘汰。
- 本场景无限定范围原型；在 C2–C5 清楚前，结论上限为 Investigate。

合规结论只来自客户法务/合规的答复或可定位的文件，本表不是法律意见。
